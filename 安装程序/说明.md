# AEpy 安装包工具（安装程序模板 + 构建器）

这套东西用来把 `AEpy/AEpython` 整个文件夹打成一个 Windows 安装包：

```
AEpy/
├─ AEpython/                  被打包的项目（build.json 里的“源目录”）
└─ 安装程序/
   ├─ 源码/
   │  ├─ 安装程序模板.cpp       安装程序（向导界面 + 解压安装），C++
   │  ├─ 卸载程序模板.cpp       卸载程序，C++
   │  └─ 安装包公共.h           公共工具：UTF-8/UTF-16、路径、CRC32、ZIP、注册表、提权
   ├─ 构建安装包.cpp            构建器源码（读 build.json → 打包 → 调编译器）
   ├─ 编译构建器.bat            编译构建器（只需跑一次）
   ├─ 构建安装包.exe            构建器：运行它就生成安装包
   ├─ build.json               构建配置（安装包名、排除打包……）
   ├─ 用户协议.JSON             用户协议正文（当前为空 = 暂无协议）
   └─ AEpython安装包.exe        生成的安装包
```

\---

\##怎么用

1. **编译构建器**
双击 `编译构建器.bat` → 生成 `构建安装包.exe`。
需要 MinGW-w64 的 `g++` 在 PATH 里（已验证：GCC 16.1 / windres 2.46）。
2. **生成安装包**

   双击 `构建安装包.exe` → 输出 `安装程序\\AEpython安装包.exe`。

   构建器命令行参数：

|参数|说明|
|-|-|
|`--keep`|保留 `%TEMP%` 下的临时构建目录，排查编译错误时用|
|`--keep-zip`|额外输出一份 `payload.zip`，方便检查到底打包了哪些文件|
|`--help`|显示帮助|

3. **测试安装包**

   双击 `AEpython安装包.exe` 走一遍向导；或者静默安装：

```
   AEpython安装包.exe --silent --dir "D:\\我的软件" --shortcut 1 --folder 1 --py 1
   ```

   `--dir` 给的是**父目录**，上面这条会装到 `D:\\我的软件\\AEpy`。

## 二、build.json

|键|说明|默认值|
|-|-|-|
|`安装包名`|生成的安装包文件名（不含 .exe），也是卸载列表里的名字|`AEpython安装包`|
|`源目录`|要打包的文件夹，相对 build.json 或绝对路径|`../AEpython`|
|`输出目录`|安装包输出位置|`.`（build.json 所在目录）|
|`模板目录`|三个模板源文件所在目录|`源码`|
|`应用名`|界面/快捷方式里显示的名字|`AEpy`|
|`安装目录名`|默认安装目录 `C:\\Program Files\\<安装目录名>`|同 `应用名`|
|`主程序`|安装目录里的可执行文件（快捷方式与“完成”时运行它）|`AEpy.exe`|
|`版本`|版本号，写进版本信息和卸载列表|`1.0.0`|
|`发布者`|发布者|同 `应用名`|
|`图标`|安装包图标（.ico）；留空则自动找 `<源目录>\\assets\\AEpy.ico`|自动|
|`排除打包`|不打包的目录/文件列表，见下|见 build.json|
|`g++` / `windres`|指定编译器路径（一般不用）|从 PATH 找|

### 排除打包的写法

* 每一项都**相对于源目录**，`./` 表示源目录根，等价写法：`./config`、`config`、`config/`；
* 路径用 `/` 或 `\\` 都行，比较时**忽略大小写**；
* 命中目录时整棵子树都不会打包；
* 支持通配符：`\*` 匹配任意多个字符（不含 `/`），`\*\*` 匹配任意多层，`?` 匹配一个字符。

实际用的规则（默认配置）：

```json
"排除打包": \[
  "./config",          // 源目录根下的 config（运行时配置，不入安装包）
  "./.venv",           // 虚拟环境（很大，不打包）
  "./\_regbackup",
  "\*\*/\_\_pycache\_\_",    // 任意层级的 \_\_pycache\_\_
  "\*\*/\*.pyc",
  "./.git"
]
```

想额外排除什么，往数组里加一行就行（例如 `"./tools"`、`"./AEpy.md"`、`"\*\*/\*.log"`）。

## 用户协议.JSON

安装程序第二步显示的内容来自 `用户协议.JSON`：

* 写成 `{"协议": "正文…"}`；也支持键名 `用户协议`、`内容`、`文本`、`agreement`、`license`、`text`、`content`；
* 值是字符串数组时按行拼接；
* 如果文件不是 JSON，就**整篇当正文**；
* 编码 UTF-8 / GBK / UTF-16 都能自动识别；
* 正文里的 `\\n` 会变成换行；
* 内容为空时（当前就是这种状态），安装界面显示“（暂无用户协议）”，用户可以直接点“下一步”。

## 安装包的行为

界面是三步向导：顶部是当前阶段提示文字，中间是内容框（换步骤就清空重画），
右下角固定是「取消安装 / 上一步 / 下一步（安装 /完成）」。

|步骤|内容|按钮状态|
|-|-|-|
|1 选择安装位置|路径输入框 + 「浏览…」，下面实时显示「将安装到：…」，三个复选框（创建桌面快捷方式 / 关联文件夹右键菜单 / 关联 .py 右键菜单），默认全勾|下一步可用，上一步禁用|
|2 阅读用户协议|只读多行文本框，显示协议正文|上一步/下一步都可用（可直接下一步）|
|3 安装|显示安装位置与选项摘要 + 进度条 + 状态文字；完成后出现「运行 AEpy」复选框（默认勾选）|点“安装”开始：安装中“上一步”禁用；装完按钮变“完成”|

### 安装位置规则

第 1 步选的是**父目录**，程序装到它下面的 `AEpy` 文件夹里：

* 选 `C:\\Program Files` → 装到 `C:\\Program Files\\AEpy`（默认就是这个）；
* 选 `D:\\我的软件` → 装到 `D:\\我的软件\\AEpy`；
* 如果选的目录本身就叫 `AEpy`（例如把默认值改成 `C:\\Program Files\\AEpy`），
就直接装进去，不会再套一层 `AEpy\\AEpy`；
* 编辑框里改路径时，下面的「将安装到：」会实时跟着变；
* `--dir` 参数（静默安装 / 提权回传）用的是同一套规则。

### 目录权限（为什么装在 Program Files 也能用）

安装到 `C:\\Program Files` 这类目录需要管理员权限，而管理员写进去的文件默认只有管理员能改。
AEpy 运行时要往自己的目录里写东西（`config\\\*.json` 配置、Python 的 `\_\_pycache\_\_`），
所以安装程序**提权安装完成后**会用系统自带的 `icacls` 给安装目录授予
`BUILTIN\\Users` 修改权限（`/grant \*S-1-5-32-545:(OI)(CI)M /T`），之后普通用户运行 AEpy
就能正常保存配置。用 `CREATE\_NO\_WINDOW` 调用，不会闪出命令行窗口。

按“安装到用户自己的目录”（不需要提权）时不做这个授权，避免把用户目录开放给其他账户。

* **取消安装**一定会弹确认框（第二步点是(Y)/否(N)，默认“否”）。
安装过程中确认取消 → 立刻停止，并把这次已经写进去的文件、创建的空目录、
桌面快捷方式、右键菜单、卸载信息全部清理掉（只删本次安装产生的，不动原有文件）。
* **自动提权**：目标目录在 `C:\\Program Files`、`Program Files (x86)`、Windows 目录下，
或者当前用户对该目录不可写时，点“安装”会用管理员权限重新启动自己
（UAC 被拒绝会提示，并留在当前界面）。提权后直接进入第 3 步并自动开始安装。
* **完成**：勾选“运行 AEpy”时点“完成”会自动启动 `主程序`；安装包是提权运行时，
会借 `explorer.exe` 以普通用户权限启动，避免编辑器一直在管理员权限下运行。
* **安装时创建的东西**

|项目|位置|
|-|-|
|程序文件|安装目录（ZIP 内目录结构原样展开）|
|卸载程序|`<安装目录>\\卸载AEpy.exe`|
|桌面快捷方式|`%USERPROFILE%\\Desktop\\AEpy.lnk`（可在第 1 步取消）|
|文件夹右键菜单|`HKCU\\Software\\Classes\\Directory\\shell\\OpenWithAEpy` → `AEpy.exe --folder "%1"`|
|.py 右键菜单|`HKCU\\Software\\Classes\\SystemFileAssociations\\.py\\shell\\EditWithAEpy` → `AEpy.exe --file "%1"`|
|卸载入口|`HKCU\\...\\CurrentVersion\\Uninstall\\AEpython安装包`（设置 → 应用 里可看到）|

  两个右键菜单的键位和项目里的 `修复AEpy右键菜单.bat`（`fix\_aepy\_menu.ps1`）保持一致。

* **卸载**：`卸载AEpy.exe`（或“设置 → 应用”）删除快捷方式、右键菜单、卸载入口和
安装目录里的全部文件；目录在 Program Files 下时会自动提权。目录里如果有**不是安装程序写入**
的文件（比如你自己放进去的资料），这些文件会保留、目录也会保留，并在结束时提示。

  卸载程序删不掉“正在运行的自己”，所以它先把自己改名搬到 `%TEMP%\\AEpyUninstall\_<进程号>.exe`，
再把安装目录整个删掉——这也是 Inno Setup 等安装器的通用做法。
那个临时副本会在**下一次安装或卸载时**自动清理，不需要人工管；
这里全程只用 Win32 API，不会弹出任何命令行窗口，也不会去 ping 任何地址（旧版本用的是一个
`cmd /c ping … \& del …` 的延迟删除技巧，已废弃）。

### 命令行参数

安装包（GUI 程序，`--silent` 时可用退出码判断成败：0 成功）：

```
--silent              静默安装，不显示界面
--dir <路径>          安装的父目录（实际装到 <该目录>\\<安装目录名>）
--shortcut 0|1        是否创建桌面快捷方式
--folder 0|1          是否关联文件夹右键菜单
--py 0|1              是否关联 .py 右键菜单
--elevated            （内部使用）标记本进程已提权
```

卸载程序：`卸载AEpy.exe --silent`（可用于 ARP 里的 QuietUninstallString）。



## 环境要求与已知限制

* 需要 MinGW-w64（`g++`、`windres`）在 PATH 中；当前用 GCC 16.1 + windres 2.46 验证通过。
* **中文路径**：MinGW 的链接器与资源编译器不能处理非 ASCII 路径，所以构建器会把模板、
ZIP、资源脚本都复制到 `%TEMP%\\AEpyInstallerBuild\\...`（纯英文）里编译，最后再把
`<安装包名>.exe` 复制回输出目录。若 `%TEMP%` 本身含中文，会自动改用
`C:\\Windows\\Temp` 或 `C:\\AEpyInstallerBuild`。
同理 `编译构建器.bat` 也用 `%TEMP%\\AEpyBuilderBuild`，并且整个 .bat 保持纯 ASCII
（cmd 会用控制台代码页解释 .bat 文本，中文会变成乱码）。
* EXE 格式限制：单个文件 < 4 GB、条目数 < 65535。
* 生成的程序是 64 位，需要 Windows 7 及以上
